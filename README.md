# Static Projects Showcase

A consolidated monorepo of static web applications organized into `<category>/<project-name>/` folders.
Categories include `games`, `landing-pages`, `tools-utilities`, and `ui-components-demos`.
To add a new project, create a subfolder under the relevant category with an `index.html` and static assets.
Register the project metadata in the `projects` array inside root `index.html` to display it in the showcase.
